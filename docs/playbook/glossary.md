# Agreed language

These are the terms King and Claude agreed for reader-facing pages. Use them exactly, and only after they
have been defined on the page.

| Term | Meaning | Define it with |
|---|---|---|
| digital citizens | AI stand-ins for real people, used to estimate how groups would respond | the page intro |
| overall answer | the answer for the whole population, from real people | "A few hundred real people give the overall answer." |
| fill in the groups | work out how each group differs from the overall answer | the short answer |
| record citizens | AI built on real people's past survey answers; predicts each real person's answer from what they said about other things | the 62-year-old woman |
| the chatbot kind | a chatbot answering in character ("You are a 62-year-old Singaporean woman") | the 62-year-old woman |
| No AI | capitalised when it names the comparison column: every group gets the overall answer | the three-columns list |
| no AI | lowercase only when it literally means a survey run without AI ("600 real people, no AI") | |
| points off | gap between an estimate and the real answer, in percentage points | 40% real vs 45% estimated = 5 points off |
| most groups | groups that answer close to the national average; the middle result | the 62-year-old belongs to several groups |
| standout groups | groups that answer very differently on a question; often minorities, the young or old, more or less educated | test examples: Malay Singaporeans and young adults; US Republicans |
| small groups | groups with few people in your survey | 150-person survey holds about 14 Indian Singaporeans |
| less error | share of the No AI error a method removes | 4.2 → 2.6 points = 38% less error |
| standard questions | questions from the big public survey included in your own survey so respondents link to the records | the pilot |

## Do not use in reader-facing copy

| Avoid | Use instead |
|---|---|
| spread, spreading | fill in the groups |
| headline number | overall answer |
| exchange rate | "about as accurate as a survey twice the size" |
| signal | whether past answers are relevant to the new question |
| regression to the mean, flattening (undefined) | "every group looks alike" |
| calibration, Bayesian pool, prior, segment | weighted by track record; groups |
| closest question | a near-identical question from a different survey |
| worst cases, big misses | including standout groups |
| simplest option | No AI |
| pattern-finding kind, real-records kind | record citizens |
| typical group | most groups |
